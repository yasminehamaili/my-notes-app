# 📝 My Notes App

A full-stack notes application built with **Next.js (App Router)**, **MongoDB**, and **Netlify Functions**.  
It allows users to create, edit, and manage their notes securely with authentication.

## 🌐 Live Demo
👉 https://app-my-notes.netlify.app/ 

## 🚀 Features
- 🔐 User authentication (signup, login, profile update)
- 📝 Create, update, and delete notes
- 📂 Upload images with notes
- 🎨 Responsive design
- ⚡ Serverless API routes powered by Netlify
- 💾 MongoDB for persistent data storage

## 🛠️ Tech Stack
- [Next.js 13+ (App Router)](https://nextjs.org/)
- [MongoDB](https://www.mongodb.com/)
- [Netlify](https://www.netlify.com/) (deployment + serverless functions)
- [CSS Modules](https://nextjs.org/docs/basic-features/built-in-css-support#adding-component-level-css)
